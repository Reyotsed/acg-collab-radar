这个网站怎么运作？

一句话：电脑不在一直开着服务器。GitHub 定时去拿公告、解析并保存成 JSON，再把 JSON 做成静态网页。你打开网站时，只是在看最新发布的那一份。

公告 ID、Wiki revid、行哈希

→
PUBLISH

重新构建 Pages

所有访客看到同一个新版本

公开网站只读构建时数据，不能在浏览器里修改 JSON。
本地 /ingest可以手动解析、确认入库和同步，但它不会部署到 Pages。
后续迁移服务器可以复用同步程序，把 JSON 换成数据库，不必重写信息源。

这份文档只保留理解系统所需的流程图。信息源、增量规则或发布方式变化时，应与代码在同一个提交中更新对应图。
